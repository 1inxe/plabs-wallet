| 项目 | 内容 |
|---|---|

| 当前版本 | v0.5.1 |
| 产品形态 | Chrome Manifest V3 浏览器扩展 |
| 文档范围 | 当前已经实现的功能、全部可达场景、安全限制和已知缺口 |

## 2. 产品定位

PLabs Privacy Wallet 是一个以 PLabs 隐私资产为核心的自托管 EVM 钱包。

产品同时管理两类账户能力：

1. **公开 EVM 账户**：持有原生币和 ERC-20，负责 dApp 连接、消息签名以及隐私交易 Gas。
2. **PLabs 隐私账户**：持有独立隐私 seed，以 `perc1...` 地址接收和管理 PLabs notes。

公开资产和隐私资产在同一钱包页按类型分组展示。用户先解锁整个插件，再按需单独解锁当前 EVM 账户绑定的隐私账户。隐私账户未解锁时，不显示隐私余额，也不能准备或提交隐私交易。

## 3. 产品目标

- 用一个插件级钱包密码解锁全部 EVM 账户。
- 为每个 EVM 账户绑定独立的 PLabs 隐私账户和隐私密码。
- 在浏览器内完成 PLabs notes 同步、断点恢复、余额计算和本地证明。
- 优先复用官网已经同步的加密状态，减少旧账户恢复时间。
- 对公开资产和隐私资产提供明确的类型、网络和可花费状态。
- 在不接受远程动态交易参数的前提下提供 Send、Receive、Shield 和受限 Unshield。
- 浏览器关闭、会话到期或用户主动锁定后，清除解锁材料。

## 4. 非目标

- 不冒充 MetaMask，也不兼容 MetaMask 私有 API。
- 不提供任意 EVM 转账、任意合约交易或 Typed Data 签名。
- 不允许网页动态指定未知合约、spender、recipient、selector 或 calldata。
- 不支持任意隐私池；隐私资产必须来自发布时固定审核的池列表。
- 不通过 Chrome Sync、远程服务或普通网页保存助记词、私钥、隐私 seed。
- 当前不支持硬件钱包、助记词派生多地址、自定义网络和账户删除。
- 当前不开放 Monad/Ethereum Privacy Swap。

## 5. 用户与核心任务

### 5.1 目标用户

- 在 Monad 或 Ethereum 使用 PLabs 隐私资产的用户。
- 需要在同一界面查看公开 Gas 资产和隐私资产的用户。
- 拥有历史 PLabs vault，需要恢复大量 notes 的用户。
- 需要多 EVM 账户，但希望只解锁一次插件的用户。

### 5.2 核心任务

1. 创建或导入 EVM 钱包。
2. 一次解锁全部 EVM 账户。
3. 创建或导入当前 EVM 账户对应的 PLabs 隐私账户。
4. 同步并恢复隐私 notes。
5. 查看公开和隐私资产。
6. 接收、发送、Shield 或 Unshield 隐私资产。
7. 连接 dApp 并执行受支持的签名。
8. 管理解锁时长、备份和网站权限。

## 6. 术语

| 术语 | 定义 |
|---|---|
| 钱包密码 | 插件级 EVM 钱包密码，一次解锁全部使用该密码加密的 EVM 账户 |
| 隐私密码 | 当前 EVM 账户绑定的 PLabs vault 密码，与钱包密码相互独立 |
| EVM 地址 | `0x...` 公开地址，用于公开资产、Gas 和 dApp 签名 |
| 隐私地址 | `perc1...` Bech32m 地址，用于 PLabs 隐私资产收款 |
| Raw 隐私地址 | 协议内部 43 字节地址，只作为内部计算和缓存主键，不面向用户展示 |
| Note | PLabs 隐私资产的本地可识别输出 |
| Spendable note | 已确认、Merkle 路径可验证且链上未花费的 note |
| Pending note | 已发现但尚未满足 Root/路径确认条件的 note |
| Shield | 从公开 ERC-20 进入 PLabs 隐私池 |
| Unshield | 从 PLabs 隐私池提取到当前 EVM 地址 |
| 同步检查点 | 已验证区块游标、区块哈希和本地加密 notes 状态 |

## 8. 信息架构

### 8.1 未解锁状态

- 只显示插件级解锁页。
- 不提供账户选择器。
- 显示 EVM 账户总数和一个钱包密码输入框。
- 一次提交解锁全部 EVM 账户。

### 8.2 已解锁状态

顶部账户区：

- 当前 EVM 账户选择器。
- 当前网络选择器。
- 添加 EVM 账户按钮。
- 锁定整个插件按钮。
- 带 `EVM` 标识的公开地址。
- 带 `隐私` 标识的 `perc1...` 地址；未创建时显示“未设置”，已锁定时使用锁定状态色。

底部导航：

1. **钱包**：公开资产、隐私解锁入口、隐私资产和隐私操作。
2. **设置**：账户名称、自动锁定、实验功能、备份和网站权限。

不再提供独立“资产”和“隐私”Tab。

## 9. 账户与密码模型

### 9.1 插件级 EVM 钱包

- 首次创建或导入时，用户设置一个钱包密码。
- 每个 EVM 助记词仍独立加密保存，但新账户统一使用当前钱包密码。
- 插件解锁时，后台使用同一个密码解密并验证全部 EVM 账户。
- 任一账户不能被该密码解密时，整个插件解锁失败，并提示存在尚未统一密码的历史账户。
- 解锁后切换 EVM 账户不再要求密码，也不会锁定整个插件。
- 历史上使用不同密码的账户需要重新导入到统一密码模型。

### 9.2 独立隐私账户

- 每个 EVM 地址最多绑定一个 PLabs 隐私 vault。
- 隐私账户使用独立密码、独立 seed、独立 KDF salt 和独立锁定时长。
- 切换 EVM 账户时，清除上一账户的隐私解锁会话。
- 解锁隐私账户后，Send、Shield、Unshield 不重复要求密码。
- 隐私交易仍必须经过证明准备、交易预览和最终广播确认。

### 9.3 会话生命周期

- EVM 和隐私会话默认在解锁 24 小时后到期。
- 可分别设置为 5 分钟、15 分钟、1 小时、4 小时、12 小时或 24 小时。
- 到期时间是绝对时间，不因普通 RPC 操作无限续期。
- Manifest V3 Service Worker 休眠后，从 `chrome.storage.session` 恢复会话。
- 完全关闭浏览器、主动锁定或会话到期后清除解锁材料。
- 主动锁定整个插件时，同时锁定 EVM 和隐私账户。
- 单独锁定隐私账户时，EVM 钱包保持解锁。

## 10. EVM 钱包功能

### 10.1 首次创建钱包

1. 用户选择“创建”。
2. 输入钱包密码并确认。
3. 本地生成 12 词助记词。
4. 使用 PBKDF2-SHA256 600,000 次派生 AES-256-GCM 密钥，加密助记词。
5. 助记词只显示一次。
6. 用户确认已离线备份后进入钱包。

异常：密码不一致、密码强度不足或未确认备份时禁止完成。

### 10.2 首次导入钱包

1. 用户输入 12 词助记词、钱包密码和确认密码。
2. 本地派生地址并加密助记词。
3. 重复地址被拒绝。
4. 导入成功后建立插件级解锁会话。

### 10.3 插件级解锁

1. 用户只输入一次钱包密码，不选择账户。
2. 后台尝试解密全部 EVM vault。
3. 校验每份助记词派生地址与保存地址一致。
4. 全部成功后建立包含全部 EVM 账户的内存会话。
5. 进入上次选择的 EVM 账户。

异常：密码错误、历史不同密码账户、vault 损坏或地址校验失败时保持全锁定。

### 10.4 添加账户

- 前置条件：插件已解锁。
- 创建或导入新账户时不再显示密码字段。
- 新账户直接使用当前统一钱包密码加密。
- 新账户创建后必须完成助记词备份确认。
- 添加成功后加入当前插件会话并成为当前账户。
- 重复地址必须拒绝。

### 10.5 切换账户

- 仅在插件解锁后可用。
- 不要求再次输入钱包密码。
- 更新 EIP-1193 `accountsChanged`。
- 清除上一账户的隐私解锁会话和 offscreen 隐私引擎。
- 加载目标账户独立的隐私账户状态。

### 10.6 网络切换

- 支持 Monad、Ethereum、Base、Arbitrum。
- 钱包内部切链立即更新当前网络和公开资产。
- dApp 请求切链时必须展示确认窗口。
- 切链后触发 `chainChanged`。
- 不允许网站添加任意自定义网络。
- 隐私 notes、池和同步状态必须按 chain ID 隔离。

## 11. 钱包页与资产

### 11.1 公开资产

- 自动读取当前链原生币余额。
- 自动读取当前 PLabs 配置中 underlying ERC-20 的余额。
- 默认只显示余额大于 0 的资产。
- 用户手动添加的 ERC-20 即使余额为 0 也保持可见。
- 资产行显示 symbol、公开类型、合约摘要和余额。
- 公开资产区域不提供发送、接收、Swap 或借贷按钮。

### 11.2 添加公开资产

1. 用户点击“添加资产”并选择“公开资产”。
2. 输入当前链 ERC-20 合约地址。
3. 后台校验地址 checksum、合约代码、`symbol()`、`decimals()` 和 `balanceOf()`。
4. 校验通过后保存到当前链自定义资产列表。

非地址、EOA、错误网络、非标准 ERC-20 或异常元数据必须拒绝。添加资产只执行只读 RPC，不产生授权、签名或交易。

### 11.3 隐私资产

- 隐私账户未设置：显示创建/导入入口。
- 隐私账户已设置但锁定：只显示带盾牌图标的“解锁隐私资产”入口。
- 隐私账户解锁后：显示操作按钮、同步状态和当前链隐私资产。
- 默认只显示总余额大于 0 的隐私资产。
- 用户从固定审核池列表添加的隐私资产即使余额为 0 也保持可见。
- 资产行显示 symbol、隐私类型、可花费余额、可花费 note 数和待确认 note 数。

### 11.4 添加隐私资产

- 只有隐私账户已解锁且当前链支持 PLabs 时可用。
- 只能从当前版本固定审核的池列表选择。
- 不接受用户手动输入任意隐私池地址。
- 添加仅改变显示偏好，不改变链上资产或授权状态。

## 12. 隐私账户创建与导入

### 12.1 创建隐私账户

1. 当前 EVM 钱包必须已解锁。
2. 用户设置并确认独立隐私密码。
3. 本地生成 32 字节随机隐私 seed。
4. 派生 `perc1...` 地址和内部 raw address。
5. 捕获 Monad/Ethereum 可信生日区块和区块哈希。
6. 加密 vault 并绑定当前 EVM 地址。
7. 自动解锁隐私账户并开始当前链同步。

### 12.2 从官网读取 vault

1. 用户选择“导入官网 vault”并点击“从 PLabs 官网读取”。
2. 如果没有打开 `https://app.plabs.online`，扩展打开官网并提示重试。
3. 如果标签页没有新版内容脚本，后台只在官网域名自动注入读取脚本并重试。
4. 内容脚本只读官网 IndexedDB：`privacybtc_wallet/seed_vaults` 和 `wallet_states`。
5. 只返回与当前 EVM 地址匹配的加密 vault 和状态。
6. 用户仍需在扩展中输入隐私密码完成解密。

扩展不得读取官网密码输入、Cookie、认证 token 或明文 seed。

### 12.3 手动导入 vault JSON

- 必须校验协议、版本、KDF、迭代次数、EVM 归属和 fingerprint。
- 密码错误、vault 损坏、归属不一致或隐私地址不一致时拒绝导入。
- 导入时间不能伪装成旧账户生日区块。

## 13. 隐私同步与恢复

### 13.1 同步触发

- 隐私账户解锁后自动同步当前网络。
- 用户可以手动点击同步。
- 同一链同时只能运行一个同步任务；重复触发复用正在运行的任务。
- Base 和 Arbitrum 不启动隐私同步。

### 13.2 新账户同步

- 从创建时捕获的可信生日检查点开始。
- 生日检查点绑定 chain ID、genesis、区块号和区块哈希。
- 不扫描生日之前的历史。

### 13.3 旧账户同步

1. 优先读取官网加密 `wallet_states`。
2. 使用隐私 seed 派生的官网状态密钥本地解密。
3. 校验 `vault_id`、fingerprint、隐私地址、chain genesis、池地址和游标区块哈希。
4. 迁移 owned notes 与可信游标到扩展缓存。
5. 重新查询每个 note 的链上 spent 状态。
6. 从已验证游标增量同步。
7. 官网没有可用状态时，从固定池部署区块执行完整历史恢复。

### 13.4 数据来源与校验

- 优先使用固定 SQD Portal 数据集读取大范围公开历史日志。
- Portal 不可用时回退到固定 RPC `eth_getLogs`。
- RPC 必须验证 chain ID 和 genesis。
- 每个扫描区间必须验证区块哈希未发生变化。
- Indexer 只用于 frozen Merkle path 等协议数据，不能单独决定余额。

### 13.5 Note 处理

1. 批量读取当前池事件。
2. 本地 WASM trial-decrypt，识别当前隐私地址的 notes。
3. 本地计算 nullifier。
4. 合并 NoteAdded 与 NoteConfirmed 状态。
5. 查询池合约 `isSpent(bytes32)`。
6. 计算总余额、可花费、待确认和已花费数量。
7. 每个完整同步页完成后保存加密检查点。

### 13.6 加密缓存

缓存包含 owned notes、nullifier、确认状态、spent 状态和可信游标。这些数据会暴露隐私持仓及交易关联，因此使用独立隐私密码派生的 AES-GCM 密钥加密后保存在扩展 IndexedDB。

缓存用于保护本机隐私、支持断点续跑并避免每次从部署区块重扫。缓存不是可信余额来源；可花费前仍需重新验证 Merkle path、anchor、cmx 和 spent 状态。

### 13.7 进度与 ETA

- 展示当前链全部隐私池的总体百分比。
- 首个扫描页完成前不显示 ETA。
- 有吞吐样本后，根据已用时间和总体百分比估算剩余时间。
- ETA 随 RPC、Portal、事件密度和本地解密速度动态更新，不构成完成时间承诺。
- 同步失败时保留已保存的完整检查点。
- 达到内部页数上限时暂停，再次同步后从检查点继续。

## 14. 隐私操作

### 14.1 通用前置条件

- 插件和当前隐私账户均已解锁。
- 当前网络与操作网络一致。
- 隐私资产同步已完成。
- Send、Shield、Unshield 的实验性主网开关已开启。
- 操作目标位于固定审核配置中。

### 14.2 Receive

- 显示当前 `perc1...` 地址二维码。
- 支持显示完整地址和复制。
- 不要求实验性写操作开关。
- 不生成签名、证明或交易。

### 14.3 Send

1. 用户选择资产、金额及 `perc1...` 或 raw 收款地址。
2. 校验地址、精度、余额和最大输入数。
3. 获取 frozen Merkle path 并本地重算 root。
4. 链上验证 anchor、cmx 和 nullifier spent 状态。
5. 本地生成 Groth16 transfer proof。
6. 展示预览，用户最终确认后广播。
7. 确认后验证输入 nullifier 已 spent 并增量同步。

### 14.4 Shield

当前只开放固定 wrapped ERC-20 pools：

1. 本地生成 Shield proof 和输出 note。
2. 固定 Relayer 返回的 `to`、`value`、calldata 必须与本地编码逐字节一致。
3. allowance 不足时只批准精确额度。
4. Ethereum USDT 已有非零 allowance 时先归零再批准。
5. 用户确认后串行发送授权和 Shield。
6. 回执必须包含从当前 EVM 地址到固定池的精确 underlying Transfer。

原生 ETH Gateway Shield 当前禁用。

### 14.5 Unshield

当前只开放 Monad sUSDC：

1. 收款地址固定为当前 EVM 地址。
2. 读取固定池费用和 fee collector。
3. 金额必须大于协议费用。
4. 本地生成证明并展示扣除、费用、到账和 Gas。
5. 广播后验证当前地址到账、fee collector 收费及输入 nullifier spent。

Ethereum Unshield 当前禁用。

### 14.6 Swap

- UI 保留入口。
- Monad/Ethereum 当前没有可验证的 Privacy Swap allowlist。
- 提交按钮始终禁用。
- 开启实验性主网操作也不能解锁 Swap。

## 15. 交易预览、广播与恢复

### 15.1 预览字段

- 网络、操作、资产、扣除金额、协议费、预计到账、收款方。
- Token 授权数量、预估 Gas、最大 Gas 成本和原生币单位。

### 15.2 安全限制

- 准备结果有效期 10 分钟。
- 广播前重新估算 Gas。
- 总最大 Gas 成本不得超过 1 个当前链原生币。
- 准备与提交时均重新确认 EVM 和隐私会话。
- 准备后账户或网络变化时拒绝提交。
- EVM 交易通过本地队列串行执行，避免 nonce 冲突。

### 15.3 操作日志

- 广播前保存操作 journal，最多保留最近 100 条。
- 状态包括 `prepared`、`approval-submitted`、`submitted`、`confirmed`、`failed-before-broadcast`、`requires-review`。
- 已广播但后续检查失败时标记 `requires-review`，不能自动重复广播。

## 16. dApp Provider

### 16.1 发现方式

- EIP-6963 名称：`PLabs Privacy Wallet`。
- 主对象：`window.plabsPrivacyWallet`。
- 兼容别名：`window.brushPrivacyWallet`。

### 16.2 支持的方法

| 方法 | 行为 |
|---|---|
| `eth_chainId` | 返回当前链十六进制 ID |
| `net_version` | 返回当前链十进制 ID |
| `eth_accounts` | 仅对已授权 origin 返回当前账户，否则返回空数组 |
| `eth_requestAccounts` | 展示连接确认，批准后保存 origin 权限 |
| `personal_sign` | 展示消息确认，校验请求地址与当前账户一致 |
| `wallet_switchEthereumChain` | 仅允许切换到内置网络，并展示确认 |
| 只读 RPC | 转发到固定当前链 RPC，并先校验 RPC chain ID |

明确拒绝：`eth_sign`、`eth_sendTransaction`、`eth_sendRawTransaction`、`eth_signTypedData_v4`、`wallet_addEthereumChain` 和其他未知写 RPC。

## 17. 网站授权

- 默认网站看不到 EVM 地址。
- 只允许 HTTPS origin 和 localhost/127.0.0.1 开发站点连接。
- 连接确认展示 origin 和当前 EVM 地址。
- 权限按 origin 本地保存。
- 设置页可查看和撤销权限。
- 撤销后 `eth_accounts` 返回空，后续签名失去授权。

## 18. 设置

### 18.1 当前账户

- 修改当前 EVM 账户名称，长度 1-32 个字符。

### 18.2 自动锁定

- 分别设置 EVM 钱包和隐私账户时长。
- 可选 5 分钟、15 分钟、1 小时、4 小时、12 小时、24 小时。
- 关闭浏览器时锁定始终开启。

### 18.3 实验性主网操作

- 默认关闭。
- 开启后允许 Send、ERC-20 Shield、Monad sUSDC Unshield。
- 不开放 Swap、Ethereum Unshield、原生 ETH Gateway Shield 或公开 EVM 交易。

### 18.4 助记词备份

- 必须重新输入统一钱包密码。
- 只展示当前 EVM 账户助记词。
- 用户可主动隐藏。

### 18.5 隐私 vault 导出

- 只导出当前 EVM 账户绑定的加密隐私 vault。
- 不导出隐私密码或明文 seed。
- 结果复制到剪贴板。

## 19. 数据与安全模型

### 19.1 持久化数据

`chrome.storage.local` 保存：独立加密 EVM vaults、当前账户和网络、隐私加密 vaults、锁定设置、网站权限、自定义资产、显示偏好和操作 journal。

扩展 IndexedDB 保存按 `chainId + pool + privacyAddress` 隔离的加密 notes 与同步检查点。

### 19.2 会话数据

`chrome.storage.session` 保存：全部已解锁 EVM 账户的临时助记词集合、统一钱包密码、会话到期时间，以及当前账户的隐私 seed、隐私密码和隐私到期时间。

该存储只允许扩展可信上下文访问，浏览器关闭后清空。内容脚本和注入页面不能访问。

### 19.3 固定依赖与网络边界

- 不执行远程 JavaScript；WASM 和 Groth16 assets 随扩展固定发布。
- 只访问 Manifest 中列出的官网、Indexer、Relayer、Portal 和 RPC。
- 隐私 seed、助记词和密码不得发送到 RPC、Indexer、Relayer 或网页。

## 21. 验收标准

### 21.1 账户与会话

- 解锁页没有账户选择器。
- 一个密码成功解锁全部统一密码账户。
- 解锁后切换 EVM 账户不出现钱包密码输入。
- 切换账户后上一隐私会话被清除。
- Service Worker 休眠但浏览器未关闭、会话未到期时保持解锁。
- 浏览器关闭、主动锁定或到期后必须重新解锁。

### 21.2 资产与同步

- 钱包页同时区分显示公开和隐私地址。
- 底部没有独立隐私 Tab。
- 公开资产没有操作按钮。
- 默认资产列表不显示零余额，手动添加资产可显示零余额。
- 隐私未解锁时不显示隐私余额或交易操作。
- 新账户从生日检查点同步；旧账户优先复用官网状态。
- 每个完整页加密落盘，pending 和 spent notes 不计入可花费余额。
- 无吞吐样本时不显示 ETA。

### 21.3 隐私操作与 dApp

- 隐私会话解锁后不重复询问隐私密码。
- 会话锁定后准备和提交均失败。
- 每笔写操作仍有预览和最终确认。
- 任一网络、池、recipient、calldata、费用、Gas 或回执校验失败时不得声明成功。
- 未授权 origin 不得读取账户。
- 任意公开交易和 Typed Data 签名保持禁用。

## 22. 已知限制与后续版本

### 当前限制

- 历史不同 EVM 密码账户不能自动统一，因为扩展不知道旧密码。
- 没有账户删除、密码迁移和自定义资产删除入口。
- 没有完整本地 Merkle Tree 快照；消费前按 note 获取并验证 frozen path。
- 单次历史恢复有页数上限，超出后需要继续同步。
- ETA 受公网 RPC、事件密度和设备性能影响。
- Ethereum Unshield、原生 ETH Gateway Shield、Privacy Swap 和普通 EVM 转账禁用。
- 主网隐私写操作仍为实验性能力，尚未完成独立安全审计。

### 后续候选

- 历史多密码账户迁移向导。
- 账户与自定义资产删除。
- 活动与交易恢复中心。
- 完整本地 Merkle Tree 快照。
- 经审计的 Ethereum Unshield 和原生 ETH Shield。
- 发布签名的隐私池配置更新机制。
- 硬件钱包、外部 Gas signer 和固定 allowlist Privacy Swap。

## 23. 发布约束

- 未完成独立安全审计前不得移除实验性主网开关。
- 不得把 Swap、Ethereum Unshield、原生 ETH Shield 或公开交易描述为已支持。
- 官网、WASM、证明电路、池配置或 ABI 变化后必须重新取证和审计。
- 发布包必须固定依赖、WASM、zkey、网络和合约配置。
- 不得自动运行冒烟测试或 UI 测试；只有用户在当前任务中明确要求时才允许执行。

# 本地操作历史

## UI 位置

- 钱包首页：隐私资产列表下方、同步信息上方放「最近活动」，展示最近 3 条。
- 「查看全部」：完整页面，按日期分组，支持操作类型/状态筛选，每页 20 条。
- 隐私资产详情：把「Notes 管理」与「操作记录」并列为页签，只展示该池的操作。
- 点记录进入详情页：显示金额、状态、创建/更新时间、支付方式、费用预览、收款地址、主交易/授权交易哈希和浏览器链接。合并显示批次，并说明是归集到自己，不是对外支出。

## 记录范围与状态

复用真实执行日志，确认提交时开始记录。覆盖发送、Shield、Unshield、合并，不把地址二维码、未提交的预览算作交易，也不伪造链上收款记录。本机未发起的交易不是这一日志的覆盖范围。

区分处理中、已确认、失败和需核对。已知 receipt status=0 显示失败；网络中断或提交结果不确定显示需核对，不自动解释为失败。Relayer/合并等已有验证材料的待处理记录可更新链上状态，普通旧记录保留实际已有信息。

紧凑历史存档与执行日志在同一次 storage.local 写入中更新，按操作 ID 去重。最多保留 1,000 条已结束操作，未结束记录保留；兼容旧日志，旧记录缺少的费用、地址等显示未记录，不能填充为零。

新加入的活动详情用当前隐私账户的状态密钥 AES-GCM 加密，AAD 绑定账户、网络和操作 ID。修改隐私密码后可通过现有状态密钥封装继续解密。历史 API 仅返回当前账户/网络，并要求独立隐私会话解锁。隐私锁定时界面清空数据，余额隐藏状态同步作用于历史金额。

这是活动详情存档的加密，不改变已有执行日志中用于恢复的公共验证材料及元数据存储方式。历史只保存在此浏览器配置，不包含在 Vault 导出中；清除扩展本地数据会失去这些记录。

按用户要求未运行测试或真实交易，仅编译打包。

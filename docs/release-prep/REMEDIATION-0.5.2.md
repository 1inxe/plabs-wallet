## 交易行为变化

- 已确认意图不再无限沿用。每次 native 签名前及广播前，后台检查主钱包和隐私会话、账户、链、实验开关、网站权限及准备结果有效期。Relayer 提交也经过最终校验。
- 确认后使用已经填充好的交易参数本地签名，随后持久化本地计算的交易 hash 与 nonce，最后发起固定 RPC 请求；不会依赖节点先返回 hash 才记录。
- 广播 timeout / HTTP 错误 / hash 不一致均保留待核对状态；不会自动创建另一笔交易来“重试”。单次回执等待约 60 秒，超时可在历史中查询。
- 所有未决 journal（含旧版普通原生交易）都阻塞同账户/链的新写操作。串行 nonce 操作与一次性准备 ID 防止重复提交同一准备结果。
- 只有能证明尚未进入网络提交阶段的新格式记录，才允许标记为未提交；缺少 hash、回执或核验材料的旧记录不会因“查不到”而自动解除阻塞。确认仅授权完成而主交易未发送时，告知用户已有授权仍可能保留。
- 自动合并预算授权绑定 worker/会话代次。锁定、切换及 worker 重启后可查询已提交批次，但下一批必须重新确认；总费用预算不因重新确认而重置。
- EVM personal_sign 同样检查授权变更与会话代次；签名期间撤销会话时，不将签名结果返回网站。

已广播交易无法撤回。若网络请求已开始，再点击锁定只能停止后续签名/发送，不能保证当前交易不上链。

## 本地数据迁移与兼容性

新增 `recovery` AES-GCM envelope，使用隐私状态密钥和单独 AAD 域。金额、recipient、nullifier、calldata 与核验对象放入密文。状态、公开钱包索引、链、操作 ID、时间、交易 hash、nonce/发送阶段和 Relayer requestId 等仍为明文恢复索引；不宣称零元数据。

只在取得对应账户的正确隐私密钥后迁移。其他尚未解锁账户的旧记录保留原样，防止用错密钥或删除恢复信息；历史备份/已泄露副本不会被迁移撤销。没有为迁移重新生成隐私 Seed、地址或改变资产。

隐私密码轮换保留同一状态密钥，因此新 recovery envelope 随既有状态密钥包装机制工作。未知 envelope 版本、损坏密文或身份 AAD 不匹配会报错，不静默替换为空记录。

迁移失败不会把隐私会话展示为成功解锁。记录结果允许在锁定后保存公开状态和既有密文，避免交易已上链但记录因锁定而丢失；恢复核验材料读取仍要求解锁。

新版本 journal 格式不向旧版提供明文 verification，因此**不要直接降级运行有未决交易的新格式配置**。EVM 恢复材料与独立隐私 Vault 仍需分别备份，操作历史本身不包含在 Vault 导出中。

## RPC 与文件边界

- 后台每 origin 每分钟最多 120 次、最多 4 个在途；全局每分钟 600 次、最多 16 个在途；来源表最多 128 个活跃窗口条目。浏览器会话内限流，不宣称跨 worker 重启持久限流。
- 网站请求体最多 100000 字符；后台 RPC 参数必须是至多 5 项数组。
- eth_getLogs 需指定合约；明确区块范围最多 2001 个区块；eth_feeHistory 最多 1024 个区块。
- dApp RPC 总时限约 15 秒，JSON 响应最多 2 MB；Indexer/证明准备的 JSON 响应最多 8 MB、约 20 秒。超过限制会明确失败，不继续无限读取。
- 导入 JSON 上限按字符串字符数计算（不是精确文件字节配额）；Vault ciphertext 最多 65536 字节、salt 16–64 字节、nonce 12 字节。KDF 超限必须从可信来源重新导出，不擅自降低输入文件的加密参数。
- JSON/网络限额可能拒绝大型第三方 dApp 查询或带巨大检查点的旧导出；这属于收紧边界后的兼容性变化。

## 仍未解决的发布事项

1. 证明引擎、电路/zkey、字体/设计资源的源码来源、完整许可证、可信设置与第三方安全审计；哈希匹配不能替代它们。
2. 合约/网关/代理升级治理与可信 bytecode 基线。未从任意 RPC 抓取当前代码就当成“审计过的可信实现”。
3. 解锁材料仍在可信扩展内存/session 中；本轮减少时长和竞态，不等同硬件隔离签名。
4. 网络服务商仍可关联 IP、查询 cmx、公开 Gas 账户和交易时间；运营方日志策略待定。
5. 无 hash 的历史不确定交易、缺少恢复证明的旧条目可能继续阻塞，需要专门核对，不能安全地一键清除后重发。
6. 发布主体、政策公开网址、支持邮箱、新版真实截图与受限环境的运行验证。

以上外部或未验证事项保持 OPEN。本轮没有发布商店或发布新的 npm SDK 版本。
